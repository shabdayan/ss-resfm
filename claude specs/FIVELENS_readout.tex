\section*{Reading guide}
The five lenses VGPA uses against RESfM, applied to our full 5-seed matrix.
\textbf{Per-scene wins} are matched-seed scene$\times$seed cells vs.\ RESfM-scratch.
\textbf{Trans med} is pooled over all scene$\times$seed cells. Errors are computed
over each method's own registered set (the same convention as VGPA Tables 1--2),
so low-coverage methods are flattered on raw error --- Nr\% is the corrective
context, and RA-AUC (which prices coverage in) is being added by the
pose-recovery program.
